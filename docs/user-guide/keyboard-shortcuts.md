# Keyboard Shortcuts Reference

Complete list of keyboard shortcuts in Projector for efficient playback control and workflow.

## Transport Control

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Play/Pause** | `Space` | Toggle playback on/off |
| **Stop** | `.` (period) | Stop playback and return to start |
| **Step Forward** | `→` (right arrow) | Move forward one frame |
| **Step Backward** | `←` (left arrow) | Move backward one frame |
| **Jump to Start** | `Home` | Seek to frame 0 |
| **Jump to End** | `End` | Seek to last frame of timeline |

## Timeline Navigation

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Zoom In** | `⌘` `=` (plus) | Zoom timeline in (show more detail) |
| **Zoom Out** | `⌘` `-` (minus) | Zoom timeline out (show more content) |
| **Fit to Window** | `⌘` `0` (zero) | Fit entire timeline in window |
| **Scroll Left** | `⇧` `←` | Scroll timeline left |
| **Scroll Right** | `⇧` `→` | Scroll timeline right |

## File Operations

| Action | Shortcut | Description |
|--------|----------|-------------|
| **New Project** | `⌘` `N` | Create new project |
| **Open Project** | `⌘` `O` | Open existing .projector file |
| **Save** | `⌘` `S` | Save current project |
| **Save As** | `⌘` `⇧` `S` | Save project with new name |
| **Import Media** | `⌘` `I` | Show import dialog |
| **Close Window** | `⌘` `W` | Close current window |
| **Quit** | `⌘` `Q` | Quit Projector |

## Editing

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Undo** | `⌘` `Z` | Undo last action |
| **Redo** | `⌘` `⇧` `Z` | Redo previously undone action |
| **Cut** | `⌘` `X` | Cut selected item |
| **Copy** | `⌘` `C` | Copy selected item |
| **Paste** | `⌘` `V` | Paste from clipboard |
| **Select All** | `⌘` `A` | Select all items in current view |
| **Delete** | `⌫` (Delete) | Remove selected item |

## Timeline Editing

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Add Audio Lane** | `⌘` `L` | Create new audio lane |
| **Remove Selected** | `⌫` (Delete) | Delete selected reel/clip |
| **Duplicate Reel** | `⌘` `D` | Duplicate selected reel |
| **Split at Playhead** | `⌘` `K` | Split reel/clip at current frame |
| **Ripple Delete** | `⌘` `⌫` | Delete and close gap |

## View Controls

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Toggle Media Library** | `⌘` `1` | Show/hide media library panel |
| **Toggle Timeline** | `⌘` `2` | Show/hide timeline panel |
| **Toggle Inspector** | `⌘` `3` | Show/hide inspector panel |
| **Toggle Full Screen** | `⌃` `⌘` `F` | Enter/exit full screen mode |
| **Show Settings** | `⌘` `,` | Open Settings window |

## Selection and Navigation

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Next Reel** | `Tab` | Select next reel on timeline |
| **Previous Reel** | `⇧` `Tab` | Select previous reel |
| **Move Selection Left** | `⌘` `←` | Move selected item earlier |
| **Move Selection Right** | `⌘` `→` | Move selected item later |
| **Nudge Left** | `⌥` `←` | Nudge selected item 1 frame left |
| **Nudge Right** | `⌥` `→` | Nudge selected item 1 frame right |

## Audio Lane Controls

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Mute Lane** | `M` | Mute/unmute selected lane |
| **Solo Lane** | `S` | Solo/unsolo selected lane |
| **Increase Volume** | `⌘` `↑` | Increase lane volume 5% |
| **Decrease Volume** | `⌘` `↓` | Decrease lane volume 5% |
| **Reset Volume** | `⌘` `⇧` `↑` | Reset lane volume to 100% |

## Playback Speed

| **0.5x Speed** | `0` | Half speed (slow motion) |
| **2x Speed** | `2` | Double speed (fast playback) |
| **Frame by Frame** | `←` / `→` | Step frame-by-frame |

## Context-Specific Shortcuts

### Media Library

When focused on Media Library:

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Quick Look** | `Space` | Preview selected media |
| **Reveal in Finder** | `⌘` `R` | Show file in Finder |
| **Get Info** | `⌘` `I` | Show media file info |
| **Remove from Library** | `⌫` | Remove selected items |

### Timeline

When focused on Timeline:

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Click to Seek** | Click | Move playhead to clicked position |
| **Drag Reel** | Drag | Move reel to new position |
| **Snap to Grid** | Hold `⌘` | Enable snapping while dragging |
| **Multi-Select** | Hold `⇧` + Click | Select multiple items |

### Video Player

When focused on Video Player:

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Full Screen** | Double-click | Enter full screen mode |
| **Escape Full Screen** | `Esc` | Exit full screen mode |

## Customizing Shortcuts

Currently, Projector does not support custom keyboard shortcuts. All shortcuts are fixed to the defaults listed above.

**Planned Feature**: Keyboard shortcut customization in Settings (v1.1)

## Tips

- **Spacebar is Your Friend**: Most common operation (play/pause)
- **Arrow Keys for Precision**: Frame-by-frame control during playback
- **Hold Command While Dragging**: Enable snap-to-grid for precise positioning
- **Use Markers**: Add markers (`M`) at key points for quick navigation
